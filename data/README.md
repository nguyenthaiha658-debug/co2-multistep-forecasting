# Data

- `co2.csv` — weekly CO2 in the air at Mauna Loa, 1958–2001, 2,284 rows.
  59 weeks are missing. The script fills them with a straight line between nearby values.
- `bike_sharing.csv` — hourly bike rentals (UCI Bike Sharing, 17,544 hours from 2011–2012).
  The experiment adds these up by day (`users` for each calendar day, 731 days).

Both files come from the time-series data in the Viet Nguyen AI machine learning course.
