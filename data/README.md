# Data

- `co2.csv` — weekly atmospheric CO2 (Mauna Loa), 1958–2001, 2,284 rows.
  59 weekly values are missing and are linearly interpolated at load time.
- `bike_sharing.csv` — hourly bike-sharing rentals (UCI Bike Sharing,
  17,544 hours from 2011–2012). The experiment aggregates this to a
  daily total (`users` summed by calendar day, 731 days).

Both files are taken from the time-series datasets bundled with the
Viet Nguyen AI machine-learning course.
